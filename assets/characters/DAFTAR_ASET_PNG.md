# Daftar Aset PNG Transparan Karakter — LoveyPix

Anda punya **2 cara super gampang** untuk memasukkan aset karakter PNG asli (background transparan):

1. **Cara 1 (Langsung di Browser):** Buka tab **🧸 Karakter** di layar kamera fullscreen LoveyPix → klik **`+ Upload PNG`** → pilih 1 atau banyak file PNG sekaligus! Stiker akan langsung muncul live di kamera dan tersimpan otomatis di browser Anda.
2. **Cara 2 (Taruh di Folder Project):** Simpan file PNG transparan ke folder ini (`assets/characters/`) dengan **nama file persis seperti tabel di bawah**, lalu refresh halaman LoveyPix — semua karakter akan langsung muncul dengan thumbnail aslinya!

> **Tips:** Klik link pencarian di kolom kanan di bawah — sudah otomatis mengaktifkan filter **PNG Transparan** (`ic:trans`) di Google Images.
